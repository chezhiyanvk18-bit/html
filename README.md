# 📰 The Daily Times

A simple, newspaper-style website presenting the latest city news in a clean and readable layout.

## 🌐 Live Website

[Visit The Daily Times](https://chezhiyanvk18-bit.github.io/html/)

## 📌 About the Project

The Daily Times is a static news website featuring a news article about the impact of free bus services on public transportation ridership in River City.

The website is designed to provide readers with news, key facts, statistics, related articles, and a subscription section in an organized newspaper-style format.

## ✨ Features

- **Home Navigation** – Easy navigation to different sections.
- **Featured News Article** – Displays the main headline and full news story.
- **News Image** – Includes a relevant image with the article.
- **Key Facts** – Highlights important information about the news.
- **Statistics Table** – Compares bus ridership between 2025 and 2026.
- **Related News** – Provides links to other news topics.
- **Contact / Subscribe** – Includes fields for name, email, and message.

## 🚀 Deployment

This website is hosted using GitHub Pages.

To publish the website:

1. Create a GitHub repository.
2. Upload the website files.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder.
6. Click Save.

GitHub Pages will generate a public link for the website.

## 📊 Featured Article

**Free Bus Trial Lifts Ridership by 18% in River City**

The featured article discusses how removing fares on 12 bus routes increased weekday ridership by 18% over six months.
